⚡ 엑셀 수정 시 대시보드 자동 배포(시트별 분리) 3가지 연동 방법

✅ 현재 상태: 업로드해주신 2026_TST_품질환경경영시스템_프로세스.xlsx (47개 시트)와 2026_TST_품질환경경영시스템_품질양식.xlsx (68개 품질양식 시트) 등 총 115개 시트 전체가 시트별로 깔끔하게 분리되어 대시보드에 내장 탑재되어 있습니다!

방법 1️⃣ [가장 추천] 구글 스프레드시트 / 클라우드 URL 자동 연동 (수정 즉시 자동 반영)

1. 엑셀 파일(2026_TST_품질환경경영시스템_프로세스.xlsx)을 Google 드라이브에 올리고 Google 스프레드시트로 저장합니다.
2. 상단 메뉴 [파일] → [공유] → [웹에 게시] (또는 링크가 있는 모든 사용자에게 보기 권한 공유)를 설정합니다.
3. 복사한 구글 시트 주소를 QMS 탭 상단의 [🔗 실시간 연동 엑셀/구글시트 URL] 칸에 붙여넣고 [연동 주소 저장 & 불러오기]를 클릭하세요.
4. 이후에는 구글 스프레드시트에서 시트를 수정하기만 하면 대시보드 접속 시 자동으로 최신 시트들이 각각 분리되어 업데이트됩니다!

방법 2️⃣ 동일 폴더(GitHub Pages / 사내 웹서버) 배포 자동 연동

대시보드 HTML 파일과 같은 폴더에 2026_TST_품질환경경영시스템_프로세스.xlsx 파일을 두고 배포(Git Push 등)하면, 대시보드가 열릴 때 자동으로 엑셀 파일을 읽어 모든 시트를 분리해 표시합니다.

방법 3️⃣ PC 엑셀(MS Excel)에서 [배포 버튼] 클릭 한 번으로 대시보드에 자동 전송 (VBA 매크로)

PC 엑셀에서 직접 수정 후 파일 업로드 없이 엑셀 안의 버튼 클릭 한 번으로 구글 시트(GAS) 서버에 모든 시트를 분리 전송하려면 아래 VBA 코드를 엑셀(Alt + F11 → 모듈 삽입)에 붙여넣으세요: 

Sub DeployAllSheetsToQMSDashboard()
    ' [2026 TST 품질환경경영시스템 프로세스] 전체 시트를 대시보드(GAS)로 시트별 자동 분리 배포
    Dim http As Object, ws As Worksheet, payload As String
    Dim docNo As String, estDate As String, revDate As String, reason As String
    Dim gasUrl As String
    gasUrl = "https://script.google.com/macros/s/AKfycbyCUtrbOvdwQ2ULnybOc-zMWfwjcpnzEC1-YL9d-oSrJYbRt5yDugd0j_Jnu3Oa_Swm/exec"
    
    Set http = CreateObject("MSXML2.ServerXMLHTTP.6.0")
    Dim count As Integer: count = 0
    
    For Each ws In ThisWorkbook.Worksheets
        If ws.Name <> "Chart1" And ws.Name <> "Sheet1" Then
            docNo = Trim(CStr(ws.Cells(5, 16).Value))
            If docNo = "" Then docNo = "TST-SHEET-" & ws.Index
            estDate = Format(ws.Cells(2, 25).Value, "yyyy-mm-dd")
            revDate = Format(ws.Cells(3, 25).Value, "yyyy-mm-dd")
            If revDate = "" Or revDate = "-" Then revDate = estDate
            reason = Replace(Trim(CStr(ws.Cells(4, 25).Value)), """", "'")
            
            payload = "{""sheetName"":""QMS"",""action"":""update"",""data"":{" & _
                      """id"":""QMS_SHEET_" & Format(ws.Index, "00") & """," & _
                      """type"":""품질표준"",""docNo"":""" & docNo & """," & _
                      """name"":""" & ws.Name & """,""rev"":""1""," & _
                      """date"":""" & revDate & """,""reason"":""" & reason & """}}"
            
            http.Open "POST", gasUrl, False
            http.setRequestHeader "Content-Type", "text/plain;charset=utf-8"
            http.send payload
            count = count + 1
        End If
    Next ws
    MsgBox "총 " & count & "개 시트가 품질 대시보드 QMS 탭으로 각각 구분되어 자동 배포되었습니다!", vbInformation, "QMS 자동 배포 완료"
End Sub
